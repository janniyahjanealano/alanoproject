# 📚 NEU CampLib
**A Library Check-in & Analytics Dashboard for New Era University.**

NEU CampLib is a mobile-first web application designed to streamline the library check-in process and provide administrators with real-time analytics on student visits across different colleges.

## 🚀 Features
* **Quick Check-in:** Mobile-responsive form for students to log their library visits.
* **Success Feedback:** Animated "Welcome" state using Framer Motion.
* **Admin Dashboard:** Real-time data aggregation showing visit counts by college (Nursing, Engineering, etc.).
* **Search:** Search-as-you-type functionality for managing user records.

## 🛠️ Tech Stack
* **Frontend:** React.js, Tailwind CSS, Framer Motion
* **Backend/Database:** Firebase Firestore
* **Hosting:** Firebase Hosting
* **Authentication:** Firebase Auth
