# **App Name**: Library Visitor Analytics

## Core Features:

- Secure Institutional Authentication: Implement Google Login restricted to institutional emails for both Admin (library staff) and Visitor roles.
- Visitor Check-in Flow: Upon login, visitors will see a form to input their 'College Department' and 'Reason for Visit,' followed by a 'Welcome to NEU Library!' notification after submission.
- Admin Analytics Dashboard: Create a dashboard showing real-time statistics. Include Stat Cards for total visitors filtered by Day, Week, and Month.
- User Management and Search: Implement a search bar to look up specific users by name and a user management table with a 'Block User' function.
- Visitor Data Storage and Filtering: Securely store visit data with timestamps, user emails, and department categories to allow filtering by undergraduate program.

## Style Guidelines:

- Color scheme: A light and professional palette, exuding a sense of academic reliability and organized efficiency suitable for a library environment.
- Primary color: Deep, desaturated blue ('#2e3b5e') chosen to convey a sense of professionalism, trust, and academic grounding, suitable for main interactive elements.
- Background color: A very light blue-gray ('#F0F3F7'), offering a clean, calm, and neutral canvas that minimizes eye strain and enhances content readability.
- Accent color: A vibrant cyan ('#2EB8D1') that is analogous to the primary color, used to highlight critical actions, active states, and important information, ensuring visibility and engagement.
- Headline and body font: 'Inter' (sans-serif) chosen for its clear, modern, and highly legible characteristics, which is ideal for data entry, status updates, and reports, maintaining a consistent professional tone.
- Use minimalist, outline-style icons that are intuitive and contribute to a clean aesthetic, enhancing functionality without distracting from content.
- Layout should be uncluttered and intuitive, featuring prominent input forms for check-ins, well-structured lists for log management, and clear, summarized views for reporting.
- Incorporate subtle, swift animations for state changes and form submissions, providing immediate feedback and enhancing the fluid user experience without unnecessary delays.
